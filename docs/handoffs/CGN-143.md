## What changed

Added an Evidence-owned application API for private manual evidence create, claim update and archive. The API derives ownership from a server-resolved Identity authorization context. Create is idempotent per owner/key; update and archive use the expected record revision. Provenance and attached-object identity remain immutable. Attached objects require a clean validation result for the same owner and key, and the repository stores the exact object revision, checksum, content type, measured size and validation time. Archive removes the record from active reads and returns only a tombstone. Unexpected repository failures are returned as a generic internal error.

## Contracts changed

Added `cgn.evidence-record.v1`, `cgn.evidence-record-create.v1`, `cgn.evidence-record-update.v1`, `cgn.evidence-record-archive.v1` and `cgn.evidence-record-archived.v1` TypeScript contracts. Consumes the existing `cgn.identity.authorization-context.v1` and `cgn.evidence-upload-policy.v1` validation result. No REST path is defined.

## Events produced / consumed

No cross-domain event is produced or consumed. Create/update/archive are visible through the Evidence-owned audit trigger, which records action, owner, evidence ID, revision and time without claim text or object keys.

## Known limitations / risks

This is a service application API; no public HTTP listener or controller exists. Its owning transport must authenticate callers and supply a server-resolved Identity context. The object validator is injected; this change does not deploy a production scanner, compose storage credentials or validate deployed retention/backups. Evidence remains private and unverified; Expert validation and confidence transitions remain in Experts.

## Rollback note

The migration is additive and has no automatic down migration. Roll back application behavior by reverting or disabling the API while retaining revision, validation and audit data. Do not drop the audit table or Evidence columns without a separately reviewed backup and data-retention plan.

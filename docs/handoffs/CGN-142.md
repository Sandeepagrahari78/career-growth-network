## What changed

Added an Evidence-owned S3-compatible storage adapter using AWS Signature Version 4 and path-style URLs. It creates short-lived, single-write upload grants with an opaque quarantine key and signed owner, content type, declared size, quarantine metadata, and If-None-Match: * headers. Post-upload inspection verifies stored size and metadata, reads the exact object revision, computes SHA-256 and checks the content signature. Download grants require the existing owner/private/clean validation gate and pin the scanned revision and checksum.

The adapter accepts endpoint, region, bucket, and credentials through configuration. It rejects non-HTTPS remote endpoints and unsafe object keys. It uses existing CGN-134 authorization and validation contracts; it does not introduce a public HTTP route, new permission path, event, or schema.

## What changed

Added an internal versioned prompt definition contract and a stateless exact
version resolver in the existing AI runtime. Each prompt version includes a
template, declared variables, model configuration, JSON response schema and
source/revision provenance. Resolution rejects missing versions without
fallback, ambiguous/invalid definitions and missing or extra variables. Safe
resolution errors and orchestration telemetry do not include prompt text or
variable values. Resolved model/schema/provenance metadata is passed to the
injected provider.

The registry definitions are supplied by the caller. This change adds no
process-local registry, persistence, route, provider credentials or real model
integration.

## Contracts changed

Added `AiPromptTemplateVersionV1`, `AiPromptVersionMetadataV1`,
`AiPromptModelConfigurationV1`, `AiPromptProvenanceV1` and
`AiPromptResolutionErrorCodeV1`. `AiGenerationRequestV1` gains an optional
`promptMetadata` field, preserving existing direct-provider calls.

## Events produced / consumed

continues to record outcome, duration and safe error code only; prompt content,
variable values and generated text are excluded.

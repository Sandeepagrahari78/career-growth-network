## Contracts changed

Added the TypeScript-only `AiGenerationRequestV1`, `AiGenerationResultV1`,
`AiProviderV1` and `AiOrchestrationErrorCodeV1` exports. The request carries
private prompt text only to the injected provider. It is not a public HTTP/API
contract. No existing contract semantics changed.

## Events produced / consumed

No domain events are produced or consumed. The runtime accepts an injected
telemetry callback and emits only an outcome, elapsed milliseconds and a safe
error code.

## Database / migration / config changes

No database, migrations, environment variables, provider credentials, paid
infrastructure, HTTP routes, production deployment or cross-service calls
were added. The workspace lock records the new package and its existing
`@types/node` dependency.

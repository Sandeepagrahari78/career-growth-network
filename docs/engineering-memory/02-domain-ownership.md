# 02 - Domain Ownership

| Domain | Owns | Must not own |
|---|---|---|
| Identity | account, auth, roles, consent | career scoring |
| Career | tracks, diagnostics, skills | social graph |
| Roadmap | plans, milestones, daily missions | evidence truth |
| Evidence | proof, provenance, confidence | public feed ranking |
| Growth | longitudinal skill/readiness state | raw auth data |
| Feed/Stories | projections/ranking | source-domain truth |
| Social Graph | follow/connect/block | message contents |
| Communities | membership/discussions/moderation metadata | identity source |
| Messaging | conversations/messages/read state | connection policy source |
| Experts | expert profile/session/validation workflow | raw evidence truth |
| Opportunities | catalog/match results | recruiter consent source |
| Recruiter | org approval/search/saved candidates | private profile truth |
| Admin/Ops | safe operational projections/audit | private-message body by default |
| Analytics | metrics/events/aggregates | business-domain source of truth |

Human ownership may vary by ticket. Architecture/security/data-contract decisions require Sandeep review.

# 08 - Agent Rules

- Do not guess missing requirements.
- Do not invent new services, schemas, events or UI flows when an approved contract exists.
- Do not bypass service ownership.
- Do not change scoring/validation semantics without explicit ticket scope.
- Do not weaken tests to make a build green.
- Do not expose private message bodies, secrets, tokens, private files or AI chat history in Admin by default.
- Do not enable paid services without explicit approval.
- Update memory after meaningful architectural or contract changes.
